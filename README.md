# Student Grade Tracker 🎓

A **Java-based Student Grade Tracker** designed to efficiently manage student records and analyze academic performance.

## 📌 Features

- ➕ Add and manage student records
- 📊 Store student grades using **Arrays and ArrayList**
- 📈 Calculate:
  - Average score
  - Highest score
  - Lowest score
- 📋 Generate a complete summary report for all students
- 🔍 Search student records
- 🗑️ Remove student records
- ✅ Input validation and error handling
- 💻 Interactive console-based interface

## 🛠️ Technologies Used

- **Java**
- **Object-Oriented Programming (OOP)**
- **Arrays**
- **ArrayList**
- **Java Collections**
- **Exception Handling**

## 🎯 Learning Objectives

This project demonstrates practical implementation of Java fundamentals, including **OOP, collections, arrays, loops, conditional statements, input handling, and data processing**.

## ▶️ How to Run

Compile the Java source files and run the main class:

```bash
javac src/*.java
java -cp src Main
```

On Windows, you can also use the included `run.bat` file.
